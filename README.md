# 🏕️ Текстовый квест "Одиночное приключение"

Проект выполнил Яшин Матвей, группа 553, преподователь Леонтьева Т.В, в рамках задания по МДК. Это консольная текстовая игра на Python, в которой игроку предстоит выживать, исследовать местность, зарабатывать монеты и искать сокровища.


## 🎯 Суть игры
Вы — путник, оказавшийся в неизвестной местности. У вас есть здоровье. С каждым ходом вы можете исследовать округу, заходить в кафе, восстанавливать силы или искать сокровища.

## 🕹️ Игровые механики (Функции)
В основе игры лежит использование функций:
*   `show_status()` — выводит текущее здоровье, количество монет и ход игры.
*   `show_menu()` — показывает доступные действия игроку.
*   `apply_damage()` и `heal()` — отнимают и восстанавливают здоровье.
*   **`search_treasure()`** — *Уникальная механика:* случайное событие. Вы можете найти монеты, получить предмет в инвентарь или угодить в ловушку.

## 🎒 Инвентарь
Игрок может копить предметы. Все найденные вещи сохраняются в список и отображаются при выборе пункта "4 - Инвентарь".
